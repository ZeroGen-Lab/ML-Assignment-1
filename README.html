评测指标与评分方式

各任务效果指标

任务指标中文解释与方向代码中的效果质量 q
LR / SVMAccuracy、Macro-F1Accuracy 是分类正确比例；Macro-F1 对各类别 F1 等权平均，兼顾不同类别。均越高越好。0.5 × Accuracy + 0.5 × Macro-F1
GBDTMAE、RMSEMAE 是平均绝对误差；RMSE 是均方误差的平方根，对较大误差更敏感。均越低越好。0.6 / (1 + NRMSE) + 0.4 / (1 + NMAE)；分别按训练目标总体标准差、围绕训练均值的平均绝对偏差归一化，退化时使用代码规定的小正数下限
KMeansARI、NMIARI 衡量扣除随机一致性的聚类一致程度；NMI 衡量聚类与类别信息的一致程度。均越高越好；聚类编号置换不直接算错。0.6 × ARI + 0.4 × NMI
HMM逐位置状态准确率、整条路径准确率前者统计状态位置预测正确比例；后者要求一条序列全部位置正确。均越高越好；解码要求 Viterbi 联合最优路径。0.8 × state_accuracy + 0.2 × exact_sequence_accuracy

这些效果指标不等于最终任务分。正式效果、正确性、鲁棒性与效率共同形成综合表现；本机 SELFTEST PASSED 不是算法质量合格线，也不是课程成绩。

先合综合原始表现，再校准任务分

组成原始表现满额含义
效果18由上表质量 q 转换，质量越好得分越高
正确性4接口与算法行为的正确性诊断
鲁棒性2边界与异常输入等诊断
效率1按正式评测的 CPU 证据与参考标定计入，不使用本机自报时间

当前实现先计算综合原始表现 R：

L = -0.6（KMeans），其它任务 L = 0
Q = min(1, max(0, (q - L) / (1 - L)))
R = 18 × Q + 正确性分 + 鲁棒性分 + 效率分

因此不能将“效果单项的 p90”当作本年度最终校准。当前实现对各任务的综合原始表现校准：每位同学在每个任务最多贡献一次有有效效果的最佳综合原始表现，计算这些样本的第 90 百分位；正常校准时以此形成满档阈值 T。B 是同套评测协议下随机预测程序的综合原始表现参考档，不是多数类、训练均值等旧无信息诊断。各组成分来自同一次提交，不能拼接多次提交的子分。

综合表现区间任务最终分（满分 25）
R ≥ T25 分；正常校准时为综合前 10% 满档，阈值处并列也进入满档
B ≤ R < T15 + 10 × (R - B) / (T - B)，在基础档与满档之间线性变化
R < B（B > 0）15 × R / B，低于基础档按比例递减

随机基础档对应 15/25，不是效果部分另加 15 分。可信完成但无有效效果的失败、无可用提交的缺项按 0 处理；仍 pending 的有效记录使结算暂缓，不产生分数或排名，平台证据缺失不冒充学生 0 分。若 B=0，有效分数的低于基础档分支不会出现。若没有有效样本，或综合 p90 不高于随机基础档，实现采用 T=25 的回退，不自动给满分，也不保证前 10% 满档；公式要求 0 ≤ B < T。真实基础档数值、CPU 参考标定及正式评测尚未完成，尚未开放，这里解释当前实现，不承诺已经测得阈值或已经产生正式成绩。

接口与源码提交

  • 保持 assignment 命名空间、类名、public 方法参数与返回类型。具体接口见 模板头文件，实现写入 assignment.cpp。
  • 可调整 private 成员，并在 include/、src/ 增加允许的标准库辅助源码。GBDT 不限定为模板树桩结构。
  • 模板 driver 负责公开 API 适配，学生无需另造评测 CLI，不将 driver 或工具装入源码 ZIP。

  • ZIP 根须含 README.md、AI_USAGE.md、include/assignment.hpp、src/assignment.cpp；其余仅允许 include/ 中 .h/.hpp 与 src/ 中 .cpp。

完整路径、文件数量、大小与格式限制见 模板说明 和 学生指南。数据、答案、模型、可执行文件、凭据与第三方机器学习库不入源码提交包。

环境配置

需要 Python 3.10+ 与兼容 C++17 的 g++ 或 clang++；工具不会自动安装编译器。服务器 Linux / GCC 12 统一评分，同一 Python 客户端生成同一格式源码 ZIP，不需要三个平台各自的评测二进制。

  • macOS：可用 Apple clang++。
  • Linux：可用 g++。
  • Windows：原生 Python、PowerShell 与 MinGW-w64 g++ / 兼容 clang++；MSVC cl 不兼容当前自测命令。WSL2 可选，不是必需。

本机自测会编译并执行 C++，不是安全沙箱，只运行自己编写或已审查的代码。

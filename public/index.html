机器学习作业一 · 学生使用说明

用 C++ 标准库从零实现五项经典机器学习算法。官方评测使用 GCC 12、C++17 和 -O2；本机开发可使用兼容编译器。

五项任务与需要实现的方法

任务需要实现的方法说明
Logistic Regressionfit / predict二分类，标签为 0/1
Linear SVMfit / predict二分类，预测保持输入顺序
GBDT Regressionfit / predict回归输出须为有限实数
K-Meansfit / predict先训练，再预测 [0, K) 内簇编号
Discrete HMMfit / predict有状态标签的监督训练；预测 Viterbi 联合最优路径

全部接口以公开头文件 starter/include/assignment.hpp 为准：保持 assignment 命名空间、类名与公开方法签名不变，可以修改 private 成员并在 starter/src/ 下增加辅助源码。仅使用 C++ 标准库，不提交预训练模型、可执行文件或第三方机器学习库。

评分规则

  • 五项任务每项25分，可任选四项；完成五项时取最高四项，总分100分，占课程总评35%。课程总评60分规定不变。
  • 效果为主，正确性、鲁棒性与效率为辅；综合表现前10%为满分档，随机/无信息基线为基础档。这是概要，不承诺只凭公开样例或单一指标获得任务25分。
  • 分类关注准确率与F1，回归关注预测误差，聚类关注划分质量，HMM关注状态与整条路径正确性；还需满足接口、合法边界、数值稳定和效率要求。
  • 每任务选取完整有效提交，不拼不同提交的子分，最终五取四。鼓励AI辅助，须如实声明并理解、验证实现；AI本身不直接加扣分。
  • 正式计算、同分与截止规则以课程题面及公告为准。评分与提交概要不修改评测程序；公开自测不产生正式课程成绩。

提交规范与时间安排

ZIP 根目录必须包含 README.md、AI_USAGE.md、include/assignment.hpp、src/assignment.cpp；其余仅允许 include/ 下的 .h/.hpp 和 src/ 下的 .cpp。两份 Markdown 均为非空 UTF-8 文本；未使用 AI 时在 AI_USAGE.md 写 No AI assistance used.。

最多 64 个文件，每文件最多 1 MiB，解压总量和 ZIP 各最多 8 MiB，每成员压缩比最多 200。禁止符号链接、路径逃逸、重复路径、凭证、数据、答案、模型及二进制。请使用随课程公告提供的工具和提交说明。

提交入口开放时间另行通知。地址、开始和截止时刻见课程公告。以服务端完成收包及校验后的接收时刻判断是否截止；每学号每天最多 10 个新提交意图、最多 1 个未完成评测任务，原意图重试不重复计次。

填写提交信息

请填写本人学号、姓名和昵称，提交及结果按学号归属。保留三个 export，学号按字符串处理并保留前导零；以下仅为虚构格式示例：

export STUDENT_ID=2026123456
export STUDENT_NAME="Zhang San"
export STUDENT_NICKNAME="zs"

学号自报不是本人认证；姓名和昵称不改变成绩归属，教师管理权限独立。设置变量后可检查本机格式：

python3 -B -m student_tools config

格式检查不提交任何数据，也不代表已登录或可提交。提交入口开放时间另行通知。

本机可用的操作：自测与打包

下载课程公告提供的完整学生包，或下载学生仓库源码 ZIP 后解压；保留 starter/、student_tools/、docs/、public/ 与 data/public/ 的目录关系，不要只下载单个源文件。公开训练数据在 data/public/training/（classification.json供LR/SVM共用，另有gbdt.json、kmeans.json、hmm.json）；五任务公开诊断输入、答案与manifest在 data/public/validation/。公开数据不随作业提交。填写模板中的 README.md 与 AI_USAGE.md 后，在解压根目录选择已实现任务运行（Windows 下把 python3 换成 python）：

python3 -B -m student_tools selftest --project starter --tasks lr,svm,kmeans,hmm --public-data data/public/validation

自测通过后打包源码：

python3 -B -m student_tools package --project starter --output submission.zip

两个工具都有 --help。学生只需要完成模板代码并自测、打包；不需要执行课程侧的组包发布操作。

安全提示：本机自测会编译并执行 C++，不是安全沙箱。只运行自己编写或已审查的代码，不替陌生人运行提交包。

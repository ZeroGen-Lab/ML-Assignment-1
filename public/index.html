获取仓库

使用 ZeroGen-Lab/ML-Assignment-1 的 Code → Download ZIP，或在自己的机器 clone。它是仓库快照，不是教师自制发行ZIP。旧v0.3.1仅历史；学生提交自己源码仍保留package步骤。

最新任务合同

C++17与C++标准库，保留Matrix接口，不调用现成机器学习库。从LR、SVM、GBDT、KMeans、HMM选四或五项；SVM保留LinearSVM符号。

GBDT为真实856维九类0..8，接口GBDTClassifier；当前公开模板仍可能旧回归，不能声称可执行新版示例。各任务200条公开训练；HMM200行=10条完整序列×20步，监督训练不拆散边界。

拟采用路径data/training/{task}/train.csv、data/training/manifest.json、data/training/DATA-SOURCES.md及data/training/gbdt/manifest.json，不代表已进main；旧data/public/training不推荐混用。

分数与公开指标

每项25×q。分类Q=0.5×accuracy+0.5×macro_f1；HMM Q=0.5×state_accuracy+0.5×exact_sequence_accuracy；KMeans Q=0.6×ari+0.4×nmi。保留原始Q，q夹到[0,1]。

所选四项全READY最高100，所选五项全READY最高125；课程同一提交至少四项READY后取最高四项，满分100。教师最终课程分另定。缺测None/null不补0，未执行NOT_RUN；baseline后置，不拿格式自测充正式分。

榜单要求显示学号、昵称、不显示姓名；所有人可点击查看该提交允许公开的真实聚合指标。这里说明要求，不表示榜/API已接通。不公开隐藏标签、逐行预测或私日志。
